# Jeu Snake – C++

Ce projet est une implémentation du jeu Snake en C++, réalisée dans le cadre du cursus à l’IHEC Carthage (2ème année Business Intelligence). Le joueur contrôle un serpent qui se déplace sur une zone de jeu et doit manger des proies pour grandir et marquer des points. Le jeu gère les collisions avec les bords de l’écran et avec le corps du serpent (game over). L’objectif est de renforcer la logique algorithmique, la gestion des boucles et des conditions, ainsi que la programmation en C++. Le code peut être compilé et exécuté en ligne de commande ou via un environnement de développement.
## Fonctionnalités
- Déplacement du serpent via le clavier
- Gestion des collisions
- Système de score

## Langage
- C++

## Objectif
Mettre en pratique la logique algorithmique et la programmation en C++.
